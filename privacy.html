Privacy Policy — Mellow Laps Uploader

Effective date: October 16, 2026

Who operates this application

Mellow Laps Uploader is operated by the owner of the Mellow Laps YouTube channel (@mellowlaps). Contact: mellowlapsyt@gmail.com.

What the application does

Mellow Laps Uploader is a private, single-user tool. It connects to the YouTube Data API so the channel owner can upload videos to their own channel, list and review the channel's videos, update video metadata and visibility, and delete duplicate uploads.

Google user data the application accesses

Through the https://www.googleapis.com/auth/youtube scope, the application accesses the YouTube account and channel data of the channel owner only — the same person who operates the application. It does not access, collect, or process data belonging to any other person, and it is not used by or offered to the public.

How the data is used

The accessed data is used solely to operate the owner's own YouTube channel: uploading videos, checking upload processing status, reading titles, durations and visibility, changing visibility or metadata at the owner's direction, and removing duplicate uploads.

Sharing

No Google user data is sold, rented, shared with, or transferred to any third party. Data is exchanged only with Google's own APIs in order to perform the actions above.

Storage and protection

The application's OAuth refresh token is stored locally on the operator's own computer in a file restricted to the operator's user account. It is not stored on third-party servers and is not transmitted anywhere other than to Google's OAuth service when requesting an access token.

Limited Use disclosure

Mellow Laps Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Because the application processes only the operator's own channel data, no user data is retained beyond what the operator keeps in their own local upload logs. Access can be revoked at any time from Google Account permissions, which immediately stops the application from accessing the account. On request by email, any stored token will be deleted.

Changes to this policy

If this policy changes, the updated version will be posted at this URL with a new effective date.
